## 4. Model training and evaluation

**Question, target and output.** The model predicts whether a stock will finish the next trading week above the median eligible stock. The label is 1 when the source price ratio from one week-start open to the next is above that week's median, so about half of each week's stocks are labelled 1. Predictions become output weights as follows: each week the top 10% of stocks by model score receive equal weight, and all others receive zero. This is a hypothetical selection output, not a measure of attainable returns. Stock-weeks without a valid outcome are excluded, never filled (section 3).

**Baselines.** Four simple rules are scored on exactly the same rows as the model: a constant score (B0), four-week momentum (B1), one-week reversal (B2), and the best single indicator (B3). For B3, the indicator and its direction were fixed on training data only: [EMR val: indicator, direction]. B3 is the headline comparison, because a model is only useful if it beats the strongest simple rule.

**Models and selection.** Before any validation run, we fixed a grid of eight configurations in the decision log (Gate 1). Logistic regression and random forest are each fitted on two pre-declared feature sets, with two settings each, and all random steps use seed 2026. Each configuration is a single Spark ML pipeline (median imputation, vector assembly, standardisation, classifier) fitted on 2013 to 2015 only, so its learned preprocessing never sees later data. Configurations were compared on 2016 validation by mean weekly AUC. Where configurations were within one standard error of the best, we chose the simplest. The best mean was [EMR val], and the frozen configuration is [EMR val]. We then recorded the frozen choice and the success rule in the decision log (Gate 2) before 2017 was read. The test set was evaluated once (code-enforced; Appendix B).

**Evaluation method.** Stocks in the same week move together, so weeks, not rows, are the unit of analysis. For each week we compute the AUC (rank-sum with tied ranks averaged), the rank correlation between scores and source price ratios, and the difference in mean log ratio between the top and bottom deciles. We then average over weeks, with 95% intervals from 10,000 week-level bootstrap resamples, and compute the paired weekly difference against B3. The success rule was fixed in advance: the model shows predictive signal only if both its mean weekly AUC interval lies above 0.5 and its paired difference with B3 lies above 0.
